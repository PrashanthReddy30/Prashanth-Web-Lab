< 1. HTML (HyperText Markup Language) >

// What we do & Why we use it:
Used to create the fundamental structure and content of a web page, including headings, paragraphs, and images.

// Benefits:
Acts as the solid base of any website, highly favorable for SEO, and universally supported by all web browsers.

// Safety:
Proper semantic markup and data sanitization to prevent malicious code injection (XSS).

< 2. CSS (Cascading Style Sheets) >

// What we do & Why we use it:
Used to design web pages by styling colors, custom layouts, and smooth visual animations.

// Benefits:
Makes the website look extremely attractive, professional, and visually engaging.

// Safety:
Enforces safe styling rules and ensures external stylesheets are loaded securely over trusted hosting.

< 3. JavaScript >

// What we do & Why we use it:
Used to build interactive features on the website such as buttons, modal pop-ups, sliders, and dynamic calculations.

// Benefits:
Enhances user experience, making the website fast, responsive, and highly dynamic.

// Safety:
Implements client-side validations and secure script handling to avoid DOM-based XSS vulnerabilities.

< 4. Node.js >

// What we do & Why we use it:
Used for server-side backend logic and managing local server databases.

// Benefits:
Delivers fast execution, real-time data handling, and scalable backend architecture.

// Safety:
Protects data through secure environment variables (.env), dependency auditing, and robust server configurations.

< 5. Firebase >

// What we do & Why we use it:
Used for cloud database storage, user authentication, and web hosting.

// Benefits:
Provides real-time data synchronization, instant configuration, and relies on secure Google cloud infrastructure.

// Safety:
Enforces strict Firestore security rules, encrypted user data storage, and token-based authentication.

< 6. Git >

// What we do & Why we use it:
Used for source code version control and tracking changes over time.

// Benefits:
Allows easy tracking of code modifications, quick rollbacks from mistakes, and seamless team collaboration.

// Safety:
Secures repositories with access tokens, private branching workflows, and prevents exposure of sensitive keys.

< 7. Netlify >

// What we do & Why we use it:
Used for rapid web deployment and continuous hosting.

// Benefits:
Offers instant global CDN distribution, automatic HTTPS certificates, and seamless GitHub integration.

// Safety:
Ensures automatic SSL/TLS encryption, secure header configurations, and protected build environments.
